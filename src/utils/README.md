# utils

> 工具函数集合

## 逻辑文件

| 文件 | 作用 |
|------|------|
| `drivingRouteUtils.ts` | 驾车路线工具：decodePolyline() 差分解码 + fetchDrivingRoute() 调用腾讯地图 API |
| `env.ts` | 环境配置：API_BASE_URL、MODE 检测 |
| `format.ts` | 格式化工具：formatMoney()/formatDate()/formatOrderStatus() |
| `storage.ts` | localStorage 封装：类型安全存取 + 统一键名管理 |
| `tmapLoader.ts` | 腾讯地图 SDK 加载器：动态创建 script 标签加载 TMap |
